Introduction to Electronics - Analog Shield Library

Arduino library and example sketches for the Analog Shield. The library uses the standard Arduino API and is developed for the Phyduino Pico; it also builds for the Arduino Uno.

Arduino library Phyduino Pico Shield Rev-C v0.1.0

Pin map

A0TEMP_SIG_MCU: conditioned temperature signal (JP2 → MCU ADC)
A1SENSOR_IN: raw temperature sensor (JP1 selects on-board U1 or external J1)
A3TEMP_SIG_EXT: conditioned temperature signal (JP2 → external ADC)
A4IR_VOUT: Sharp GP2Y0A21YK0F IR distance sensor (J2)
A5POT: potentiometer RV1
2ENC_SW: rotary encoder switch, active low
3ENC_A: rotary encoder A, active low
4ENC_B: rotary encoder B, active low
5LED2: red LED D2, active low
6LED1: green LED D1, active low
